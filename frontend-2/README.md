# frontend-2

React client for Unified Business Platform backend.

## Setup

```bash
cd frontend-2
npm install
npm run dev
```

The Vite dev server proxies `/api` to `http://localhost:8080` (Spring Boot default).

## Features

* Authentication (login/register/profile)
* Browse products, place orders, view and update orders
* Invoice lookup and payments
* Create/list/support tickets with comments

Expand by editing files under `src/pages` and `src/components`.
